## Locations

Set the scene with a Fountain slugline — `INT.`, `EXT.`, `INT./EXT.`, or
`I/E.` followed by the place:

```
INT. KITCHEN
INT. JEANGREY'S ROOM
INT. DANGER ROOM - NIGHT
```

Time suffixes: `- MORNING`, `- DAY`, `- EVENING`, `- NIGHT`.

> Watch out: the place name must match a location the project knows, with
> exact capitalization. An unknown slugline is a compile error (with a
> "did you mean…?" suggestion) — the valid places come from the
> [allowlist](#allowlist).
